# Reading Rhythm Dashboard

A small, dependency-free dashboard for seeing current-book progress and recent reading activity at a glance.

## Run locally

Open `index.html` in a browser. No build step or package install is required.

## Quality checks

```bash
npm test
npm run check
```

The dashboard includes sample reading data, progress cards, session summaries, a responsive activity table, and a genre filter for focusing the reading log. The app keeps data and calculations in plain JavaScript so future features can remain easy to review and test.
